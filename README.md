# BEN AI Shopee Affiliate

MVP dashboard statis untuk mengelola katalog produk, estimasi komisi, draft konten promosi, tautan affiliate, dan performa manual.

## Jalankan
- Buka `index.html` di browser, atau aktifkan GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.
- Jika Pages sudah aktif, alamat situs: https://3pitribahgiajaya.github.io/affiliate-bot/

## Fitur
- Database produk lokal di browser.
- Estimasi komisi per produk dan skor peluang indikatif.
- Generator draft caption, hook, CTA, dan hashtag.
- Link manager dan salin tautan.
- Catatan klik, pesanan, dan komisi aktual manual.
- Ekspor CSV serta backup/pulihkan JSON.

## Batasan
- Belum terhubung ke akun atau API Shopee Affiliate.
- Tidak melakukan scraping, login, pemesanan, atau posting otomatis.
- Integrasi resmi memerlukan akses API/partner yang disetujui Shopee dan backend aman.
- Data disimpan di localStorage browser/perangkat. Buat backup sebelum mengganti browser atau membersihkan data.
- Estimasi komisi bukan pendapatan yang dijamin.
